NAMUNA BETHEL JYOTI CHURCH — STARTER APP

This is a bilingual English/Nepali, mobile-friendly Progressive Web App starter using the church logo supplied in the chat.

BEFORE PUBLISHING
1. Open config.js and add the official YouTube channel URL, sermons playlist URL, prayer request Google Form URL, giving provider URL, and events calendar embed URL as applicable.
2. Replace placeholder descriptions with church-approved service times, pastor/leader details, announcements, and worship resources.
3. Test all links and both languages. Do not publish a donation link until church leadership verifies it. Restrict prayer request form access to the authorized prayer team and explain who can read submissions.
4. Use only hymn lyrics, Bible text, photos, and recordings that the church has permission to publish.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account and create a public repository named namuna-bethel-jyoti-church.
2. Upload every file and folder in this project to the repository root (not the ZIP itself).
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for the published HTTPS URL shown in Settings > Pages.
5. Test the link on an iPhone and Android phone. HTTPS is required for PWA installation/service worker features.

INSTALL ON PHONES
- iPhone: open the published URL in Safari > Share > Add to Home Screen > Add.
- Android: open the published URL in Chrome > menu > Install app (or Add to Home screen).

IMPORTANT LIMITATIONS
- This PWA is not automatically published in the Apple App Store or Google Play. Store publication is a separate process and may have fees and review requirements.
- The supplied YouTube name is not enough to identify a verified channel URL. The current button searches YouTube for the church name until the official channel URL is added to config.js.
- Prayer request and giving links are placeholders until the church supplies verified destinations.
- This starter has no member accounts, private database, push notifications, or administrative dashboard. Do not collect confidential pastoral information in an unsecured public form.
